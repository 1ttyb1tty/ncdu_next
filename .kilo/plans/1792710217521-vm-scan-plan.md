# Plan: document/image/audio/video/text/source/markup scanning + multi-tab TUI with per-tab scans

**Goal:** Extend ncdu-next so scanning a machine/drive/FS/sub-tree classifies documents, office files, images, audio, video, text variants, programming languages, and markup languages by extension (fast default), and — under `--detect-format` — detects text encoding and line-ending variation. Wrap everything in a multi-tab TUI: each tab is an independent navigation/scan session with its own root path, scan state, and optional in-flight scan, cancellable per-tab, switchable with number keys.

## Decisions (resolved)

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Detection default | Extension heuristics | Zero content reads; fast on machine-wide scans |
| Detection secondary | Magic-byte + encoding via `--detect-format` flag (CLI) + `d` keypress toggle (TUI) | Opt-in I/O cost; user-controlled |
| Type representation | `Type string` on `tree.Node` | Flows to TUI/export/web |
| Encoding/line-ending representation | Separate `Encoding string` + `LineEnding string` fields on `tree.Node` | Keeps `Type` clean; only meaningful for text-ish files; populated only under `--detect-format` |
| Encoding/line-ending eligibility | Types with prefix `text-`, `source-`, `markup-` | Office/image/audio/video are binary → not eligible |
| Extension→type map | Hardcoded in `internal/scan` for v1 | Zero-config; defer configurability to v2/v2.5/v3 |
| Tabs | Max 8 tabs (constant); each owns root path, scan state (idle/scanning/done/error), result tree, navigation state, per-tab options | Small fixed bound; easy to raise later |
| Tab switching | Number keys `1`–`8` switch tabs; `Ctrl+Tab`/`Ctrl+Shift+Tab` cycle; tab bar shows `1 2 3 …*` with `*` on active | Direct access + cycling |
| New tab | `t` opens a new idle tab (root popup, no scan); tab 1 at startup auto-scans CLI `--path`. Scan-in-new-tab (`n`) and detailed-scan-in-new-tab (`N`) deferred to v2; in v1 use `t` → `r` → `s` (or `d` before `s` for detailed). | `t` is single-key consistent; reduces v1 key surface and code paths |
| Close tab | `x` closes current tab; last tab can't be closed (quit app instead) | Prevent zero-tab state |
| Edit root | `r` enters popup prompt for root path in current tab | Idle tab needs root before scan |
| Start/rescan | `s` starts/rescans current tab's root; explicit to avoid accidental heavy scans | Safety |
| Detect-format toggle | `d` toggles detect-format on/off for current tab; triggers background re-scan if tab has a root | Separate from `e` view toggle |
| Scan cancellation | Each tab's scan has its own `context.Context`; cancelling in-flight scan stops workers; switching tabs does NOT stop in-flight scans | Background scans persist across tab switches |
| Loading state | TUI shows "scanning…" indicator for any tab with an in-flight scan | Feedback during heavy work |
| Concurrency | Up to 8 concurrent scans (one per tab max) | Bound by tab count |
| Tab scan status | Tab struct holds `Status ScanStatus` where `ScanStatus` is a typed string with constants: `Idle`, `Scanning`, `Done`, `Error`; `Deleting` reserved for v2 (delete trigger out of scope v1) | Tracks current/last operation per tab; `Deleting` reserved for future delete work |
| Tab bar status display | Tab bar shows `N<status>` e.g. `1*[scanning]`, `2[done]`, `3[error]`, `4[idle]`; `*` marks active tab | User can see operation state of every tab at a glance |
| Status transitions | `Idle`→`Scanning` when scan starts (startup or `s`/`d` toggle); `Scanning`→`Done` on success; `Scanning`→`Error` on failure; `Scanning`→`Idle` on cancel (previous results retained if any); `Error`→`Scanning` on retry (`s`) | Explicit, bounded state machine |
| Cancel behaviour | Cancelling a scan sets status `Idle` (retains previous tree results if present, else idle); in-flight scans keep running when switching tabs | Safe cancellation, no data loss of prior results |

## Encoding & line-ending detection (`--detect-format`, text-ish only)

Reads first up-to-8 KB of each eligible file:
1. BOM check: `EF BB BF` → utf-8; `FF FE` → utf-16-le; `FE FF` → utf-16-be; `FF FE 00 00` → utf-32-le; `00 00 FE FF` → utf-32-be.
2. No BOM: validate UTF-8 over buffer → `utf-8`; else all bytes < 0x80 → `ascii`; else `latin-1`.
3. Binary guard: any NUL byte → not text; leave encoding/line-ending empty.
4. Line endings counted: CRLF (`\r\n`), standalone LF (`\n` not preceded by `\r`), standalone CR (`\r` alone). Highest count wins; if ≥2 categories each >0 → `mixed`; if no newlines → empty.

Encoding values: `utf-8`, `utf-16-le`, `utf-16-be`, `utf-32-le`, `utf-32-be`, `ascii`, `latin-1`; empty when not detected.
Line-ending values: `crlf`, `lf`, `cr`, `mixed`; empty when not detected.

## Concrete integration (walker.go)

Add `fileProps(path string) (fileType, encoding, lineEnding string)` on `Walker`:

```go
func (w *Walker) fileProps(path string) (string, string, string) {
    fileType := detectFileType(path)
    if !w.opts.DetectFormat {
        return fileType, "", ""
    }
    fileType = RefineType(path, fileType)
    if isTextType(fileType) {
        encoding, lineEnding := RefineText(path, fileType)
        return fileType, encoding, lineEnding
    }
    return fileType, "", ""
}
```

`isTextType(fileType string) bool` → `strings.HasPrefix(fileType, "text-") || strings.HasPrefix(fileType, "source-") || strings.HasPrefix(fileType, "markup-")`.

All 3 file-node creation sites (single-file root, symlink-target file, regular file) replace `Type: w.fileType(p)` with:
```go
ft, enc, le := w.fileProps(p)
child := &tree.Node{Name: name, Path: p, IsDir: false, Size: size, AppSize: size, Type: ft, Encoding: enc, LineEnding: le}
```

## TUI data flow

**Startup:** tab 1 auto-scans CLI `--path` root. Other tabs idle.
**New tab (`t`):** creates idle tab; popup prompt asks for root path; no scan starts. In v2, `n` (auto-scan new tab) and `N` (auto-scan new tab, detect-format on) will be added.
**Start/rescan (`s`):** current tab's scan starts with its root + detect-format preference; tab status transitions `Idle`→`Scanning`→`Done`/`Error`; tree replaced on completion; cancel in-flight scan first if running.
**Detect-format toggle (`d`):** flips current tab's detect-format flag; if root set, triggers background re-scan.
**Switch tabs:** number keys / Ctrl+Tab; in-flight scans keep running in background.

## Failure modes

- Unknown extension → `Type` = `""`, other fields empty; scan continues
- `RefineText` read fails → keep extension `Type`, leave encoding/line-ending empty, log verbose, continue scan
- Scan cancelled → tab status `Idle`, previous results retained if present; error not surfaced as fatal
- Root path invalid → tab status `Error`, error shown in tab, not fatal to app
- `export.Read` on file missing new fields → fields default to `""` (backward compatible)
